# private/ — 내 데이터. git이 무시한다.

```
exports/    뱅크샐러드 "파일로 받기" xlsx 원본 (여러 개 가능, 기간 겹쳐도 됨)
profile.yaml   내 재무 프로필 — templates/profile.yaml 을 복사해 인터뷰로 채움
rules.csv      가맹점 → 카테고리 룰 (인터뷰 답이 쌓이는 학습장)
setup/      01_진단.md · profile.draft.yaml · 02_질문지.md · 03_확인필요.md (생성물)
ledger/     ledger.csv (생성물) · overrides.csv (거래 한 건에 대한 내 답)
out/        financial_profile.md · cashflow_monthly.csv · category_monthly.csv · balance_sheet.json (생성물)
```

이 폴더를 통째로 클라우드 동기화 폴더에 두지 말 것. 백업이 필요하면 zip에 비밀번호를 걸어서.
